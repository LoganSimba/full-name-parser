FullNameApplication A simple Java console application that collects a user’s full name by prompting for each part individually. The program uses separate methods for first name, middle name, last name, and suffix, then prints the full formatted name.

📌 Features Prompts the user for:

First name

Middle name

Last name

Suffix (optional)

Uses individual methods for each input

Trims extra whitespace

Outputs the full name in a clean formatted style
